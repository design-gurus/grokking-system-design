# Security Policy

This repository contains documentation and learning content (Markdown files), not deployable software. Security issues are rare, but they can still happen, for example a malicious link, a compromised GitHub Actions workflow, or content that exposes sensitive data.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Instead, report it privately through GitHub:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, where it is (file path or link), and how it could be exploited.

We will acknowledge your report as soon as we can and keep you updated while we look into it.

## Scope

- Links in the content that point to malicious or hijacked sites
- Issues in the workflows under `.github/workflows`
- Any content that leaks credentials or personal data

Typos, factual errors, and broken links that are not malicious belong in a regular issue using the **Content error** template.
